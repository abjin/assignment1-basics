## Headline results

All training on a single RTX A6000 (the handout budgets assume B200, which is
several times faster, so wall-clock figures are not comparable to it).

| Dataset | Best validation loss | Note |
|---|---:|---|
| TinyStories | **1.358** (`batch-256`) | target was ≤ 1.45; baseline 1.374 and `lr-3e-3` 1.361 also clear it |
| OpenWebText | **4.049** | naive baseline cited by the handout is 5.0 |

13 training runs in total; every run's config and JSONL log is committed under
`runs/<name>/` (checkpoints are gitignored).

## Reproducing

```sh
# 1. data + tokenizer + uint16 token arrays
python3 -m cs336_basics.prepare_data \
    --train data/TinyStoriesV2-GPT4-train.txt \
    --valid data/TinyStoriesV2-GPT4-valid.txt \
    --vocab-size 10000 --out-dir data/tinystories

# 2. train (ablation flags: --no-rmsnorm --post-norm --no-rope --ffn-type silu)
python3 -m cs336_basics.train --data-dir data/tinystories --out-dir runs/tinystories-base

# 3. sample
python3 -m cs336_basics.generate --run-dir runs/tinystories-base \
    --tokenizer data/tinystories/tokenizer.pkl --prompt "Once upon a time" \
    --max-new-tokens 256 --temperature 0.8 --top-p 0.9

# 4. figures
python3 scripts/plot_curves.py
```

`scripts/run_experiments.sh` chains the full experiment suite and resumes any run
that was interrupted (it skips runs that already have `final.pt`).
